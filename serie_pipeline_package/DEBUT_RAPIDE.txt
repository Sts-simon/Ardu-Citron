Pour generer un episode complet, ouvre un terminal dans ce dossier, dans l'environnement Python ou Manim fonctionne, puis execute:

python serie_pipeline.py script_annote.txt voix_off.mp3 guidage_ep01_court.py --cue-map cue_map.json --scene Unguided --output-dir build_ep01 --align-only

Verifie build_ep01/alignment_report.txt. Si les reperes sont corrects, relance sans --align-only.

Installation de WhisperX si necessaire:
pip install whisperx

Voir README_serie_pipeline.md pour les details et les dependances Manim/FFmpeg.
